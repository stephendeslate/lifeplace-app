# Analytics and Metrics

The Analytics dashboard provides business performance data to help you track bookings, revenue, and client trends. Navigate to **Analytics** in the top navigation to get started.

## Date Range and Comparisons

Use the date range picker at the top of the page to set your reporting window. Presets are available for common ranges (Last 7 Days, Last 30 Days, Last 90 Days, This Year, Last Year). The default view shows the last 30 days. Trend indicators compare the current period against the previous period of equal length, so you can spot changes at a glance.

## Key Performance Indicators

The dashboard displays two rows of KPIs:

| Category | Metrics |
|----------|---------|
| Primary KPIs | Total Bookings, Total Revenue (with trend arrow), Conversion Rate, New Clients |
| Secondary KPIs | Confirmed, Completed, Cancelled, Average Booking Value |

## Report Tabs

Seven report tabs provide detailed breakdowns across different areas of your business:

| Tab | What It Covers |
|-----|----------------|
| Sales & Reservations | Revenue trends, booking pipeline, package performance |
| Events & Guests | Event counts, guest totals, event type distribution |
| Customers & Leads | Client acquisition, lead sources, repeat client rates |
| Operations | Venue utilization, staff workload, scheduling density |
| Booking Flows | Funnel analysis from inquiry to confirmed booking |
| Questionnaires | Response rates, completion times, form performance |
| Communications | Email open rates, message volume, response times |

## Sales and Reservations Detail

The Sales tab includes a revenue chart that can be viewed by day, week, or month. A pipeline chart shows bookings across each stage, and a revenue-by-package table breaks down earnings by your configured packages.

## Exporting Data

1. Navigate to the report tab you want to export.
2. Click the **Export** button within the tab's section (each tab has its own export controls).
3. Data is exported in **CSV** format.
4. Available exports include a bookings summary, revenue report, customer list, and lead sources report.
