# Analytics and Metrics

LifePlace provides two complementary dashboards: **Analytics** for business intelligence and **Metrics** for operational insights.

## Analytics Dashboard

Navigate to **Analytics** to access business performance data.

### Revenue Analytics
- Total revenue and revenue trends over time
- Revenue broken down by event type

### Booking Analytics
- Conversion rates from lead to confirmed booking
- Booking volume over time

### Client Analytics
- New vs. returning client ratios
- Top clients ranked by revenue

### Event Type Breakdown
- Which event types are most popular
- Which event types are most profitable

### Lead Source Effectiveness
- Which marketing channels drive the most bookings
- Comparative performance across lead sources

## Metrics Dashboard

Navigate to **Metrics** to access operational and technical data.

### Platform Impact
- Overall platform utilization
- User engagement levels

### System Health
- API response times
- Error rates
- Uptime monitoring

### DORA Metrics
Technical delivery metrics for the engineering team:
- Deployment frequency
- Lead time for changes
- Change failure rate
