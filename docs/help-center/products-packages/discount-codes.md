# Discount Codes

Discount codes let you offer special pricing to clients through promotions, loyalty rewards, or negotiated deals. You control the type of discount, who can use it, and when it applies.

## Discount Types

| Type | Description |
|------|-------------|
| Percentage | Reduces the total by a percentage (e.g., 15% off) |
| Fixed | Subtracts a flat amount from the total (e.g., 5,000 PHP off) |
| Free Hours | Grants a number of complimentary hours (e.g., 2 free hours of venue use) |

## Application Types

| Type | Description |
|------|-------------|
| Automatic | Applied automatically when conditions are met — no code entry needed |
| Code Required | Client must enter the discount code during the booking process |
| Admin Only | Can only be applied by a team member from the admin side |

## Creating a Discount Code

1. Navigate to **Settings > Commerce > Discount Codes**.
2. Click **New Discount Code**.
3. Choose the discount type and enter the value.
4. Select the application type.
5. Set **validity dates** to define when the code is active.
6. Configure **usage limits** — both a total redemption cap and a per-client limit.
7. Save the discount code.

## Minimum Requirements

You can set minimum thresholds that must be met before a discount applies. Options include a minimum order amount and a minimum number of booked hours. This ensures discounts are only used on qualifying bookings.

## Scoping to Products or Categories

Discount codes can be restricted to specific products or categories. For example, a "CATERING20" code could apply only to products in the Catering category, leaving other line items at full price.

## Client Experience

When a discount code is set to "Code Required," clients enter it during the **Pricing Summary** step of the booking flow. Automatic discounts appear without any action from the client. Admin-only discounts are never visible to clients.
