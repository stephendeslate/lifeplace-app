# Recording and Tracking Payments

This article covers how to view, create, and manage payment records in LifePlace.

## Payment Statuses

| Status | Meaning |
|---|---|
| CREATED | Payment record created |
| PENDING | Awaiting processing |
| PROCESSING | Currently being processed |
| COMPLETED | Payment successfully received |
| FAILED | Payment attempt failed |
| CANCELLED | Payment was cancelled |
| REFUNDED | Payment was refunded |

## Viewing All Payments

Navigate to **Payments** in the top navigation bar to see all payments across all events. From this view you can:

- Search by payment number or reference
- Filter by payment status

## Recording a New Payment

1. Navigate to **Payments > Add Payment** (or use the payment action from the event detail page).
2. Fill in the following fields:
   - **Event** -- the associated event
   - **Amount**
   - **Currency** (PHP, USD, EUR, SGD, HKD)
   - **Due Date**
   - **Payment Method**
   - **Status**
   - **Reference Number**
   - **Description** (e.g., "50% deposit")
   - **Notes**
   - **Manual Payment** -- toggle this switch on for cash or bank transfer payments
3. Click **Create Payment** (or **Update Payment** when editing an existing record).

Payment numbers are auto-generated by the system.

## Payment Detail Page

Click any payment to view its full details:

- Amount, status, and payment method
- Associated event and client
- Receipt information (number and date)
- Reference number
- Processing details
