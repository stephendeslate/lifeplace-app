# Glossary

Key terms used throughout LifePlace.

| Term | Definition |
|---|---|
| Event | A booking or engagement with a client -- the central entity in the system |
| Lead | An initial inquiry that has not been confirmed yet |
| Quote | A pricing proposal sent to a client |
| Invoice | A billing document generated after a quote is accepted |
| Payment | A record of money received from a client |
| Contract | A legal agreement between the company and client |
| Workflow | An automated sequence of actions tied to an event's lifecycle |
| Workflow Stage | One step in a workflow (e.g., send email, create task) |
| Booking Flow | The client-facing wizard for submitting a new booking request |
| Event Type | Category of event (Wedding, Corporate, Birthday, etc.) |
| Venue | A physical location type at the property (Cabana, Open Field, Sanctuary). Represents a venue type, not an individual unit. |
| Product/Package | A sellable item or bundle with pricing |
| Product Category | Grouping for products (event packages, wedding combos, etc.) |
| Questionnaire | A form sent to clients to gather event-specific information |
| Communication Template | Reusable email or SMS template with variable placeholders |
| Email Layout | Branded HTML wrapper applied to all outgoing emails |
| VIP Program | Loyalty system with tiers and benefits for repeat clients |
| Notification Type | Configurable notification category with templates and channels |
| PHT | Philippine Time (UTC+8) -- the timezone used throughout the system |
| DPA | Data Privacy Act (Philippines) -- the system includes consent and privacy request tracking |
| Pricing Summary | The booking flow step where clients review pricing, apply discounts, and accept terms |
| Ingress/Egress | Setup time before an event (ingress) and teardown time after (egress), from venue operating rules |
