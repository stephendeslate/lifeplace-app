# Using the Calendar

The calendar provides a visual overview of all your events, availability, and scheduling conflicts. Navigate to **Calendar** in the top navigation to get started.

## Calendar Views

The calendar supports two views, selectable from the toolbar:

- **Month View** — Displays color-coded event chips on each day. Up to three events are shown per day; additional events appear as a "+N more" link that expands the full list.
- **Week View** — Shows event cards with more detail, including an action menu accessible through the three-dot icon on each card.

## Toolbar and Navigation

Use the toolbar to move between dates and refine what you see:

1. Click the **Previous** and **Next** arrows to navigate by week or month.
2. Click **Today** to return to the current date.
3. Use the **search bar** to find events by name, client, or keyword.
4. Open the **filter panel** to narrow displayed events.

| Filter | Options |
|--------|---------|
| Event Status | Lead, Confirmed, Completed, Cancelled |
| Event Type | Dynamic — configured in **Settings > Booking Configuration > Event Types** |
| Availability | All Dates, Available Only, With Conflicts |

## Availability and Conflicts

Dates display availability badges to indicate open or booked status. When multiple events overlap, a conflict warning indicator appears so you can review and resolve scheduling issues.

## Creating Events and Exporting

- Click the **Add Event** button to open the event creation form directly from the calendar.
- Click **Export** to download a CSV file of all events currently displayed in the view.

## Display Settings

The calendar includes five display toggles accessible from the settings icon: Show Availability Indicators, Show Conflict Details, Highlight Unavailable Dates, Show Availability Statistics, and Enable Real-time Updates. Adjust these to customize your view.
