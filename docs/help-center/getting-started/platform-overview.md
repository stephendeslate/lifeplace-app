# Platform Overview

LifePlace is a full-stack event management platform designed for Philippine venues. It handles the entire booking lifecycle -- from initial client inquiry through event completion -- across three applications.

---

## Applications

| Application | Who uses it | What it does |
|---|---|---|
| **Admin CRM** | Staff (you) | Manage clients, events, contracts, payments, workflows, and all business operations |
| **Client Portal** | Customers | Browse venue information, submit booking requests, view quotes, sign contracts, make payments |
| **Mobile App** | Staff on the go | Access key CRM features from mobile devices |

---

## Key Conventions

**Time:** All dates and times are displayed in Philippine Time (PHT, UTC+8). There are no timezone conversions anywhere in the platform. The Philippines does not observe daylight saving time, so PHT is consistent year-round.

**Currency:** All monetary values are in PHP (Philippine Peso).

---

## Navigating the Admin CRM

After logging in, you land on the Dashboard. The top navigation bar gives you access to all major sections of the platform.

### Navigation Bar

The admin CRM uses a flat horizontal header bar with the following items:

| Nav Item | What It Does |
|---|---|
| Dashboard | Overview of key metrics, recent activity, and quick actions |
| Analytics | Business analytics -- revenue, bookings, conversion rates |
| Tasks | View and manage tasks assigned to you and your team |
| Events | All events -- create, view, manage the full event lifecycle |
| Calendar | Visual calendar view of all events |
| Clients | Client database -- view, create, and manage client profiles |
| Payments | View and manage payments, invoices, and billing |
| Metrics | Performance metrics and KPIs |
| Settings | System configuration -- templates, products, workflows, and more |
