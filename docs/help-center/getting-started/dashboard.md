# Dashboard

The Dashboard is your home base in LifePlace. It gives you a high-level view of what is happening across your venue's operations and provides shortcuts to common actions.

---

## What the Dashboard Shows

### Key Metrics

At the top of the Dashboard, you will see summary KPIs:

- **Event Revenue** -- revenue from events
- **Total Revenue** -- total revenue recorded across all sources
- **Active Clients** -- total registered clients
- **Upcoming Events** -- events scheduled in the near future
- **Conversion Rate** -- percentage of booking sessions converting to confirmed events

### Recent Activity & Alerts

Below the metrics, the Recent Activity section shows your 3 most recent notifications, giving you a quick look at the latest updates without leaving the Dashboard.

### Quick Actions

The Dashboard provides buttons to jump directly to common tasks:

- **Create Event** -- start a new event
- **Add Client** -- add a new client to the system
- **View Analytics** -- go to the Analytics page
- **Payments** -- go to the Payments page

### Tasks Summary

The Tasks Summary widget shows your pending tasks, giving you a quick view of action items that need your attention.

### Upcoming Events

A list of your upcoming events so you can see what is coming next.

### System Status

The System Status section provides a quick health summary based on system activity indicators such as unread notifications and pending payments.

---

## Best Practices

Start each work session on the Dashboard to see what needs your attention. Check for:

- New pending tasks that have been assigned to you
- Recent notifications that may need a response
- Events approaching their dates that may need follow-up
- System status for any activity that needs attention
