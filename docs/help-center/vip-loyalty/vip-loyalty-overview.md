# VIP & Loyalty Overview

The VIP and Loyalty program rewards your most valued clients with exclusive benefits, priority treatment, and special pricing. It helps you build long-term relationships and encourage repeat bookings through a structured tier system.

## How the Program Works

Clients earn their way into VIP tiers based on their activity with your venue. Once they reach a tier, they unlock benefits that apply to future bookings. The program runs alongside your normal booking flow — clients see their status and perks directly in their portal.

## Earning Methods

Clients can advance through tiers using three independent earning methods. Each method is a toggle that can be enabled or disabled independently — you can have multiple active at the same time.

| Method | Description |
|--------|-------------|
| Automatic | Tier upgrades based on spending, completed bookings, or both (configurable). When enabled, select the automatic earning type: Spending, Bookings, or Both. |
| Points-Based | Clients earn points per currency spent, redeemable for rewards |
| Manual | Staff assigns tier status directly |

## Tier System

Tiers are arranged in a hierarchy with ascending levels. Each tier has qualification thresholds based on spending, number of bookings, or accumulated points. Clients automatically move up when they meet the requirements for the next level.

## Benefits

Each tier can include any combination of the following ten benefit types.

| Benefit Type | Description |
|--------------|-------------|
| Percentage Discount | Percentage off booking totals |
| Fixed Discount | Flat amount off booking totals |
| Free Hours | Complimentary excess venue hours |
| Waive Service Charge | Service charge fee removed |
| Waive Late Fee | Late payment fee removed |
| Waive Rescheduling Fee | Rescheduling fee removed |
| Priority Booking | First access to date selection |
| Early Access | Preview of new packages before public release |
| Exclusive Package | Access to packages available only to this tier |
| Complimentary Add-On | A free additional service |

## Application Modes

Benefits can be applied in two ways. **Automatic** benefits are applied to every qualifying booking without any action. **Redeemable** benefits cost a set number of points and must be claimed by the client.

## Client Portal Experience

Clients see a status card displaying their current tier, a progress bar toward the next level, and a list of their available benefits. This transparency motivates continued engagement with your venue.

## Membership Status and Expiration

| Status | Meaning |
|--------|---------|
| Active | Client is currently enrolled and earning |
| Expired | Membership lapsed due to expiration rules |
| Suspended | Membership paused by an administrator |

Expiration can be configured as **Never** (lifetime membership), **Inactivity** (expires after a period with no bookings), or **Annual** (resets each year).
