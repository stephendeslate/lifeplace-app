# VIP & Loyalty Configuration

This guide walks you through setting up and managing your VIP and Loyalty program. All configuration is done from a single area with three tabs: Program Settings, Tiers, and Benefits.

## Accessing Configuration

Navigate to **Settings > Commerce > VIP & Loyalty** to open the program configuration panel.

## Program Settings Tab

The Program Settings tab controls the overall behavior of your loyalty program.

1. Use the **master toggle** to enable or disable the entire program.
2. Enable one or more **earning methods** — Automatic, Points-Based, and Manual are independent toggles that can be active simultaneously.
3. If Automatic earning is enabled, select the **auto earning type** — Spending, Bookings, or Both.
4. If Points-Based earning is enabled, configure:
   - **Points per currency spent** — how many points clients earn per unit of spending
   - **Points expiry months** — how long points remain valid before they lapse
5. Set **expiration settings** to determine how memberships expire (never, inactivity period, or annual reset).
6. Toggle **client visibility** options to control what clients can see in their portal (tier progress, points balance, available benefits).

## Tiers Tab

The Tiers tab is where you define the levels of your program.

1. Click **Add Tier** to create a new level.
2. Enter the tier **name** and assign a **level number** to set its position in the hierarchy (higher numbers rank higher).
3. Set **qualification thresholds** — the spending amount, booking count, or point total required to reach this tier.
4. Customize the tier's **appearance** with a color and icon for display in the client portal.
5. Mark one tier as the **default** — this is the starting tier for all new clients.

| Setting | Description |
|---------|-------------|
| Name | Display name for the tier (e.g., Gold, Platinum) |
| Level | Numeric rank determining hierarchy |
| Thresholds | Spending, bookings, or points required to qualify |
| Color & Icon | Visual styling in the client portal |
| Default | Starting tier assigned to new clients |

## Benefits Tab

The Benefits tab lets you assign perks to each tier.

1. Select a tier, then click **Add Benefit**.
2. Choose the **benefit type** (percentage discount, free hours, priority booking, etc.).
3. Enter the **value** — for example, 10 for a 10% discount or 2 for two free hours.
4. Set **usage limits**: per booking (how many times it applies in a single booking) and per month (total uses across all bookings in a calendar month).
5. For redeemable benefits, specify the **points cost** the client must spend to claim the perk.
