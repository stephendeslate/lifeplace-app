# Quotes & Pricing

Quotes are how you communicate pricing to clients in LifePlace. A quote bundles line items, taxes, discounts, and terms into a single document that a client can review and accept. Once accepted, the system automatically moves the event forward -- generating contracts and invoices as configured.
