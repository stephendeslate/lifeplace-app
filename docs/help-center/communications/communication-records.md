# Communication Records

Communication Records provide a complete history of all outbound messages sent through LifePlace.

## Viewing Communication History

Navigate to **Records** using the main navigation or go directly to `/records`. The records list shows every communication sent from the platform, including:

- **Emails sent to clients** -- quote notifications, contract deliveries, payment reminders, and other automated or manual messages
- **Email template used** -- which template generated the message
- **Delivery status** -- whether the email was sent, delivered, bounced, or failed
- **Associated event and client** -- each record links back to the relevant event and client, so you can quickly jump to the full context

Use the records view to audit what was sent, troubleshoot delivery issues, or confirm that a client received a specific communication.
