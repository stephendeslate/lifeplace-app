# Communication Templates

Communication templates let you define reusable email and SMS content with dynamic placeholders that are filled in automatically when a message is sent.

## Managing Templates

Navigate to **Settings > Templates > Communication Templates** to create and edit templates.

## Template Features

### Variable Placeholders

Templates support dynamic variables that are replaced with real data at send time. Examples include:

- Client name
- Event date
- Quote total
- Venue name

The available variables depend on the template's context type.

### Context Types

Each template is assigned a context type that determines which variables are available:

- **QUOTE** -- variables related to quotes and pricing
- **CONTRACT** -- variables related to contracts and legal terms
- **GENERAL** -- general-purpose variables available in all contexts
- Other context types as configured for your workflows

### Email Layouts

Templates can be paired with an email layout to wrap the content in consistent branding (header, footer, and styles). See [Email Layouts](email-layouts.md) for details on configuring layouts.
