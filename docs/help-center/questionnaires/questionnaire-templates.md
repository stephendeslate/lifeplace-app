# Questionnaire Templates

Questionnaire templates let you define reusable sets of questions that can be attached to bookings automatically or on demand. Instead of building a questionnaire from scratch each time, create a template once and apply it consistently across events.

## Accessing Questionnaire Templates

Navigate to **Settings > Template Management > Questionnaire Templates** to view, create, and manage your templates.

## Creating a Template

1. Click **New Template** from the templates list.
2. Enter a descriptive **name** (e.g., "Wedding Planning Details").
3. Select the **event type** the template applies to, or leave it open to all types.
4. Set the **ordering** to control where this template appears in your list.
5. Save the template, then begin adding fields.

## Adding Fields

1. Click **Add Field** within your template.
2. Choose a **field type** from the available options (text, number, date, select, etc.).
3. Mark the field as **required** if clients must answer it before submitting.
4. For select and multi-select fields, define the **options** clients can choose from.
5. Add a **description** to provide context or instructions for the client.
6. Set **placeholder** text to guide expected input format.

## File Upload Settings

For file-type fields, you can configure additional constraints.

| Setting | Description |
|---------|-------------|
| Max file size | Maximum size per uploaded file |
| Allowed types | Permitted file formats (e.g., PDF, JPG, PNG) |
| Max files | Maximum number of files a client can upload |

## Conditional Display

Fields can be configured to appear only when specific conditions are met. For example, show a "Please describe" text field only when a client selects "Other" from a dropdown. This keeps questionnaires concise and relevant to each client's situation.
