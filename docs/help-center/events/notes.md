# Notes

Add notes to events, clients, and other records to keep your team informed. Notes help you capture important details, special requests, and internal reminders in one place.

## Adding a Note

1. Open the event or client profile in the admin dashboard.
2. Navigate to the **Notes** section.
3. Click **Add Note**.
4. Fill in the note details and click **Add Note**. When editing an existing note, the button reads **Update Note**.

Each note includes the following fields:

| Field | Required | Description |
|-------|----------|-------------|
| Title | No | A short label to identify the note at a glance |
| Content | Yes | The body of the note — any relevant details or instructions |
| Visible to client | No | Toggle that controls whether the client can see this note |

Each note also automatically records a **Created by** attribution, so your team can see who added the note.

## Client Visibility

By default, notes are private and only visible to your admin team. To share a note with a client, enable the **Visible to client** toggle when creating or editing the note. Only notes that are explicitly marked as visible will appear in the client portal.

This gives you full control over what clients see. Use private notes for internal coordination — such as vendor contacts, setup logistics, or staff assignments — and shared notes for communicating directly with the client about their event details.

## Where Notes Appear

- **Event profiles** — notes attached to a specific event are shown in the event detail view.
- **Client profiles** — notes attached to a client appear on their profile page, useful for tracking preferences or communication history.
