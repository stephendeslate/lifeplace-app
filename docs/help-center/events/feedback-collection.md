# Feedback Collection

Gather client feedback after events to measure satisfaction and collect testimonials. The feedback system supports star ratings, written comments, and public reviews that can be shared on your venue's profile.

## How Feedback Works

After an event is completed, clients can submit feedback through the client portal. Each client may submit one feedback entry per event — duplicate submissions are automatically prevented.

## Rating System

Feedback includes both an overall rating and category-specific scores:

| Rating Type | Scale | Description |
|-------------|-------|-------------|
| Overall rating | 1 to 5 stars | General satisfaction with the event experience |
| Category ratings | 1 to 5 stars | Specific scores for: Communication, Organization, Quality of Service, Timeliness, and Value for Money |

Clients can also leave written comments describing their experience in detail.

## Public Testimonials

When submitting feedback, clients can choose to make their review public. Public testimonials are displayed on your venue's profile and can be used in marketing materials. Private feedback is only visible to your admin team.

## Responding to Feedback

The API supports admin responses to feedback entries. A dedicated admin UI for responding to feedback is coming soon.

Once available, responses will be visible to the client, making it easy to acknowledge positive reviews or address concerns promptly.

## Where Feedback Appears

**For admins:**
- Feedback data is collected via the client portal, but there is no dedicated admin UI for viewing or responding to individual event feedback yet. Backend support exists and an admin interface is coming soon.
- Aggregated ratings and trends are available in your analytics reports.

**For clients:**
- Clients submit feedback from the event detail page in the client portal.
- The **Reviews** page in the client portal displays public testimonials from all clients, not a personal review history.
