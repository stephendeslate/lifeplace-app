# Files and Documents

Attach and organize files for any event. Contracts, quotes, payment receipts, requirement lists, and photos can all be stored directly within the event profile for easy access by your team and your clients.

## File Categories

Every uploaded file is assigned a category to keep documents organized:

| Category | Typical Use |
|----------|-------------|
| Contract | Signed agreements and booking contracts |
| Quote | Cost estimates and pricing proposals |
| Payment | Receipts, proof of payment, and transaction records |
| Requirements | Technical riders, setup instructions, and checklists |
| Photo | Event photos, venue shots, and inspiration images |
| Other | Any file that does not fit the categories above |

## Allowed File Types

The platform accepts the following formats:

- **PDF** documents
- **Word** documents (.doc, .docx)
- **Images** — JPG, JPEG, and PNG

## Uploading Files

**From the admin dashboard:**

1. Open the event profile and select the **Files** tab.
2. Click **Upload File**.
3. Choose a category, select your file, and optionally add a description.
4. Toggle **Make file visible to client** to control whether the client can see the file.
5. Click **Upload** to upload.

**From the client portal:**

Clients can upload files from their **Documents** page. Client-uploaded files are automatically visible to your admin team.

## Version Tracking

Each file has a version field that you can set manually when uploading. When you upload an updated version of a document, set the version number accordingly. Previous file entries are preserved so you can review the history of changes over time. Version tracking is manual — the system does not automatically increment version numbers.

## Controlling Visibility

Each file has a public flag that determines whether clients can view it in the client portal. Internal documents such as planning notes or draft contracts can be kept private until you are ready to share them.
