# Early Check-in and Late Checkout

For venues with operating rules configured, events can request adjusted arrival and departure times:

- **Early Check-in** -- arrive before the default check-in time. This may incur an additional fee.
- **Late Checkout** -- leave after the default checkout time.

These adjustments are tracked on the event record with:

- Requested check-in or checkout time
- Number of additional hours
- Associated fees (if applicable)
